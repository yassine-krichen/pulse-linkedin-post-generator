# POSTED.md — Archive of Published Content

This is your record of what's been published. Use it to:
- Track posting consistency
- Avoid repeating topics
- Build a portfolio of your LinkedIn work
- Spot patterns in what resonates

---

## How to Use This File

After posting a piece of content:

1. **Move** the markdown from `examples/` to a backup or archive folder
2. **Add an entry** below with:
   - Date published
   - Post title
   - Content type (Standard / Carousel / Image)
   - Topic category
   - LinkedIn post link (if available)
   - Optional: performance notes, engagement observations

## Topic Categories (For Tagging)

Use these to organize and avoid repetition:

- **Systems** — Architecture, scaling, design patterns
- **Full-Stack** — End-to-end development, cross-layer insights
- **ML/AI** — Models, training, inference, agents
- **DevOps** — Infrastructure, automation, deployment
- **Cloud** — AWS, GCP, Azure, cloud patterns
- **Lessons** — Mistakes learned, retrospectives
- **Certifications** — Courses completed, achievements
- **Projects** — Specific project retrospectives or launches
- **Industry** — Observations about tech trends, career
- **Tutorial** — How-tos, step-by-step guides

## Notes

- **Consistency matters** — 1 post per week is the goal. This archive helps you stick to it.
- **Topics evolve** — As your role or focus shifts, your topics will too. That's natural.
- **Repurposing is OK** — Different angle on the same topic? Different format? Post it. POSTED.md shows you what's been covered.
- **Performance tracking (optional)** — If you want, note engagement stats. Not required, but helpful for learning what resonates.
