## How to Use This File

1. **Add ideas as they occur** — don't lose them, capture them here
2. **Annotate with context** — what happened? what did you learn? who's the audience?
3. **Mark status** — `[ ]` = pending, `[→]` = in progress, `[✓]` = posted
4. **Move to POSTED.md** after publishing with date and performance notes
5. **Keep 4–6 ideas queued** so you never run dry on content
